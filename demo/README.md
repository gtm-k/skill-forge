# Demo Skills

This folder contains sample skills you can use to try out SkillForge without creating your own first.

## How to Use

1. Open `SkillForge.html` in your browser
2. Click **Open Skills Folder**
3. Select this `demo/` folder
4. Browse, edit, and experiment with the sample skills

## Included Skills

| Skill | Description |
|-------|-------------|
| `code-reviewer` | Review code changes for quality, security, and standards |
| `git-commit-writer` | Generate conventional commit messages from staged changes |
| `api-doc-generator` | Create structured API documentation from code or specs |
| `bug-report-triage` | Assess bug reports for severity and prioritize them |
| `daily-standup-prep` | Prepare concise standup updates from recent activity |

These are fully valid [agentskills.io](https://agentskills.io) skills — you can use them with any compatible agent (Claude Code, Codex, Cursor, Copilot).
